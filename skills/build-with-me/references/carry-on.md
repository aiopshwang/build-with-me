# 이어가기

## 걸음 끝 두 줄, 보이게
걸음이 끝날 때마다 [`진행.md`](../assets/진행.md) 맨 아래에 "지금까지 된 것 / 다음" 두 줄을 쓰고 [`지도.md`](../assets/지도.md)의 걸음에 ✓. 그리고 **말로** ★: "이 작업은 중요하니 여기까지 적어둘게요 — 다음에 이어서 할 때 이걸 읽어요." git 커밋(`bwm: <걸음 이름>`)은 보이지 않게. 같은 종류의 반복 걸음은 기록만 하고 설명은 생략.

## 재개 (새 세션·맥락 정리 직후)
걸음을 시작할 때마다, 그리고 맥락이 정리된 직후(compaction) **첫 행동은 `진행.md` 읽기**. 마지막 두 줄을 말한다: "지난번엔 여기까지: <지금까지 된 것>. 다음은 <다음>이에요. 이어서 갈게요." 프로젝트의 `CLAUDE.md`/`AGENTS.md`에 적힌 [`project-note.md`](../assets/project-note.md) 한 줄이 이걸 다시 시키므로 학습자는 아무것도 기억할 필요가 없다. `진행.md` 첫 줄의 버전이 이 스킬과 다르면 형식을 조용히 맞추고 한 줄로 알린다.

## '안 돼요' 프로토콜
학습자는 에러를 붙여넣지 않는다. 에이전트가 **먼저 스스로 본다**: 방금 실행한 명령의 출력, 만든 파일, `.bwm/serve.json`의 포트로 curl. 그래도 모르면 딱 하나만 묻는다: "화면에 빨간 글자가 있으면 그대로 복사해서 붙여주세요." 학습자에게 진단을 시키지 않는다. 같은 곳에서 두 번 막히면 `지도.md` "막힌 곳"에 적고 더 작은 걸음으로.

## 에러 번역 세 줄
**무슨 일** / **왜**(한 줄, 비유 허용) / **뭘 할지**. 예: "화면이 못 떴어요 / 아까 쓰던 문이 아직 닫히지 않아서 새 문을 못 열었어요 / 다른 문으로 다시 열게요." 스택트레이스·파일명·함수명은 말하지 않는다.

## 요구가 바뀌면
북극성을 다시 쓰고(규칙 1) 지도를 다시 만든다. 이미 ✓된 걸음은 그대로 둔다. 원래 요구가 범위 밖이면 "그건 2탄"에.

## archive
"새로 시작"이면 스킬이 만든 파일만 `archive/<YYYY-MM-DD>/`로 옮긴다: `진행.md`, `지도.md`, [`내-말로.md`](../assets/내-말로.md), `index.html`, `config.js`, `access-rules.json`, `.bwm/`. 학습자의 다른 파일은 건드리지 않는다. 지우지 않는다.

## 강사에게 보내기
종결 경로에서, 그리고 학습자가 "도와줄 사람이 있어요"라고 하면: "막히면 `진행.md`와 `지도.md` 두 파일을 강사(또는 동료)에게 보내세요. 이 두 파일엔 열쇠가 없어서 그대로 보내도 돼요." (`guard.py pre-share`가 두 파일도 검사한다.)
